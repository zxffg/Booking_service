# Booking System бот на основне телеграм
**Стек используемых технологий:** python 3.14, uv 0.10, aiogram 3.28, psycopg 3.3, dotenv 1.2, redis 7.4
## О проекте
Бэкенд разработан для отработки взаимодействия python, redis и postgresql. За основу была выбрана бизнес-логика бронирования номеров в отеле. Пользователь может посмотреть свою историю бронирования, удалить запись, а также создать новю бронь: выбрать дату саезда и выезда, а также выбрать свободный номер на эти даты. Когда пользователь делает выбор, в redis появляется блокировка номера на период 600-та секунд (10 минут), чтобы пользователь мог сделать оплату. После оплаты бронь подтверждается, если что-то пошло не так, то через указанное время жизни блокировки - она снимется. Также реализована функция кэша - информация о забронированных номерах хранится именно там.

В процессе также были изучены: connection-pool, Redis TTL и EX, разделение проекта а грамотную архитектуру

## Использование/запуск бота
1. Клоинровать репозиторий
2. Командой `uv pip install -r requirements.txt` установить все зависимости
3. Прописать свои параметры подключения к PostgreSQL, Redis, tgBot TOKEN в переменную окружения.
4. Запустить бота в режиме полинга командой `uv run python3 -m bot.main`
