# Booking System — Telegram бот для бронирования номеров

**Стек используемых технологий:** Python 3.14, uv 0.10, aiogram 3.28, psycopg 3.3, python-dotenv 1.2, Redis 7.4

## О проекте

Бэкенд разработан для отработки взаимодействия Python, Redis и PostgreSQL. За основу была взята бизнес-логика бронирования номеров в отеле. Пользователь может посмотреть историю бронирований, удалить запись, а также создать новую бронь: выбрать дату заезда и выезда и выбрать свободный номер на эти даты.

Когда пользователь делает выбор, в Redis появляется блокировка номера на 600 секунд (10 минут) — чтобы пользователь успел оплатить бронь. После оплаты бронь подтверждается. Если оплата не прошла, блокировка автоматически снимается по истечении времени жизни ключа. Также реализован кэш — информация о подтверждённых бронях хранится в Redis до даты выезда.

В процессе были изучены: connection pool, Redis TTL, разделение проекта на слои (repository, service, handlers).

## Запуск

1. Клонировать репозиторий
2. Установить зависимости: `uv pip install -r requirements.txt`
3. Заполнить `.env` файл своими параметрами подключения к PostgreSQL, Redis и Telegram Bot Token
4. Применить схему БД: `psql -d bookings -f db/schema.sql`
5. Запустить бота: `uv run python3 -m bot.main`
